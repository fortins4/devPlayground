# Ríocht: Get Up to Speed

Read this file before doing any Ríocht task. These are the locked rules. Each new locked rule is added here when it's made.

## Workflow
- 2026-10-13: Read this file before doing any task.
- 2026-10-13: Whenever a new locked rule is made, it is added to this file.
- 2026-10-12: Merges to main are approved only by the user's A/B in Lead's chat. The user doesn't approve in Godot's chat. If Godot won't act on a relayed approval, Lead does the fast-forward push itself.
- 2026-10-08: Build only what the user picked from a numbered list. No extra test scenes, areas or features without asking first.
- 2026-10-08: Every suggestion, rough-edge list or set of options is numbered so the user can reply with a number, never bullets.
- 2026-10-07: For approved multi-item queues, Godot keeps building the next items locally without waiting on A/B for the previous one. Stills and an A/B still go to the user for each ship.
- 2026-10-06: Verify assumptions before relaying them. Check frames of user clips directly; don't trust automated video descriptions.
- 2026-10-05: Every combat change passes the engine smokes plus mid-arc stills before an A/B; end poses alone aren't enough.
- Standing: no push, PR, merge or release without the user's explicit yes.

## Opening sequence
- 2026-10-08: The opening is a set sequence: Máire, then bucket to spring to trough, then knife hitch, then bringing the herd home, then stow and meal.
- 2026-10-08: In the herd step the bogged cow is one of the 6 at the pasture. Free her, drive her back to rejoin the herd, then drive all 6 home. The stray dog ambushes and scatters them on the lane. Penning needs 6/6, and the walk out is quiet.
- 2026-10-08: Máire is the hub. After each task Cian returns to her, and she gives the next task, which unlocks only after that talk. She has no lines when he's away.
- 2026-10-08: Máire waves when she has something to say and says it automatically when Cian comes near (no button). Each pending line plays once, then the next step unlocks.
- 2026-10-07: The farm's water source is a natural spring dug out into a ditch scoop, not a village-style well.

## Combat and movement
- 2026-10-06: There is no stamina system at all: no meter, drain or gates on attacks, charges or sprint.
- 2026-10-06: Cian can walk normally while attacking (charge, release, swing, jab, settle). Feet stay planted and natural; sprint still blocks attacks.
- 2026-10-06: While sprinting with the goad, Cian carries it in one hand at his side (head forward, butt trailing, off the ground) with the other arm pumping. The second hand rejoins the shaft when the sprint ends.
- 2026-10-06: Empty arms while sprinting and walking swing clear beside the torso, not through it.
- 2026-10-06: Releasing sprint returns the goad into the current mouse look-guard, and look-guard stays live while walking.
- 2026-10-05: While sprint is held, look-guard stays down and attacks and charges can't start. Continuous goad swings clear their held flag so return-to-ready stays correct.
- 2026-10-05: The high guard always starts the overhead goad chop from the bar. Left, right, top and down zones are equal size. Look-guard and attack aim use the same mouse regions.
- 2026-10-04: Both hands stay on the goad, and the shaft never clips the body in any direction through the whole fight.
- 2026-10-02: Attacks use three directions: top, left and right. Holding attack and then releasing charges power. The goad adds a chargeable stab as the bottom attack.
